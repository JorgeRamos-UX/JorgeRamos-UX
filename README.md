I'm a **Product UX designer with an engineer's mind**. I trained in Cybernetic Electronics Engineering, so I start with how the system works, and only then design the screen.

I design products end to end, and the tools that help teams build them well: design systems, Design Ops and AI agents. At **[Hexalis](https://hexalis.org/en/)**, an open source nonprofit, I'm the product designer behind its Design System and Design Ops Toolkit.
